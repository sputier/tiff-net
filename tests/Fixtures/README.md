# Test fixtures

Where each fixture comes from, so that it can be regenerated and its licence is known.

| Folder | Content | Origin |
| --- | --- | --- |
| `interop/manifest.json` | the list of the tifffile corpus and the SHA-256 of the samples of each dataset | written by `tools/make_fixtures.py --update`; committed |
| `interop/generated/` | the corpus itself (about 6 000 files, 140 MB): 11 sample types × 1 to 4 channels (extra channel unspecified, associated or unassociated alpha) × compressions × predictors × strips/tiles × interleaved/planar × classic/BigTIFF × little/big endian, 53 × 37 pixels. Predictor 2 on 64-bit integers, which tifffile does not write, is encoded by the script itself and checked by reading it back with tifffile | written by `python -I tools/make_fixtures.py` with the versions of `tools/requirements-interop.txt`; not committed, generated by the `interop` CI job |
| `domain/` | 45 small files (each under 1 MB) for the cases of the design: Siril 1.4.4 output (8/16/32-bit grey and RGB, Astro-TIFF FITS header in `ImageDescription`, ICC profile, Deflate), thumbnail in IFD0, multi-page, sub-IFD pyramid, grey with 3 samples, associated and unassociated alpha, 1/2/4/12/14-bit samples, MinIsWhite, palettes, float16, complex (refused), the 8 orientations, metadata (ICC, XMP, resolution, sample range, private tags), UTF-8 description, Pillow output (ICC, Deflate, JPEG, palette) | written by `python -I tools/make_domain_fixtures.py` (Siril files only where `siril-cli` is installed); committed with `manifest.json`, which holds the SHA-256 of each file, what tifffile reads in each page, and what this library must deliver when it differs |

All the data is synthetic, drawn from seeded generators; the Siril files are made from a synthetic frame, drawn from a seeded generator, not from a real observation: there is no third-party image and no licence question.
